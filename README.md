# 肉鸽贪吃蛇 Rogue Snake

肉鸽（Roguelike）+ 贪吃蛇的融合玩法：单图无尽模式，吞食豆子触发进化，技能皆有代价。单个 HTML 文件，零依赖，浏览器打开即玩。

## 在线试玩

直接用浏览器打开 `index.html` 即可。也可以在仓库 **Settings → Pages** 中开启 GitHub Pages（Source 选择 main 分支根目录），即可通过网址在线游玩。

## 玩法规则

- 🫘 **吞食进化**：累计吞食豆子到 **10 / 20 / 30 / 50 / 70 / 90 / 120…**（步进每 3 次升一档）触发一次进化
- 🃏 **三选一技能**：每次进化从 3 张随机技能卡中选 1 张
- ⚖️ **力量皆有代价**：选择技能会在地图上生成对应数量的随机障碍（如圣盾 = 3 个障碍），障碍永久累积
- 💀 **永久死亡**：撞墙、撞障碍、撞到自己即本局结束，最高分自动保存
- 📈 **自然难度**：进化越多，移速越快、地图越挤

## 技能卡池（9 种）

| 技能 | 效果 | 代价 |
|---|---|---|
| 🛡️ 圣盾 | 抵挡一次致命碰撞（可叠加） | 3 个障碍 |
| 🧲 食物磁铁 | 靠近的豆子被自动吞食（范围+1） | 3 个障碍 |
| 💰 黄金胃 | 豆子得分 +50%（可叠加） | 4 个障碍 |
| ⚓ 稳定锚 | 移速 -15%，操控更稳（可叠加） | 2 个障碍 |
| ✂️ 瘦身剪 | 立即缩短 30% 的身体 | 2 个障碍 |
| 🌀 相位穿越 | 穿过边界，从另一侧出现 | 5 个障碍 |
| 🦎 断尾求生 | 获得一次撞身不死的机会 | 4 个障碍 |
| 🍀 幸运星 | 豆子有 30% 概率变为金豆（+50分） | 3 个障碍 |
| 🧹 大扫除 | 清除地图上所有障碍物 | 无代价 |

## 操作方式

| 平台 | 操作 |
|---|---|
| 电脑 | 方向键 / WASD 移动 · 空格暂停 · 数字键 1/2/3 选卡 |
| 手机 | 手指滑动控制方向 · 点按卡片选技能 |

## 打包成可安装程序

同一套代码可以打包成各平台安装包：

- **Windows（exe）**：用 Electron + electron-builder 打包
- **安卓（APK）**：用 Capacitor + Android Studio 打包

详细步骤见 [docs/游戏打包与发布指南.md](docs/游戏打包与发布指南.md)
