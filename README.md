# 肉鸽贪吃蛇 Rogue Snake

肉鸽（Roguelike）+ 贪吃蛇的融合玩法：无尽地牢、随机地图、三选一强化、永久死亡。单个 HTML 文件，零依赖，浏览器打开即玩。

## 在线试玩

直接用浏览器打开 `index.html` 即可。也可以在仓库 **Settings → Pages** 中开启 GitHub Pages（Source 选择 main 分支根目录），即可通过网址在线游玩。

## 玩法规则

- 🗼 **无尽层数**：每层地图随机生成障碍物，吃够目标数量的食物后开启**传送门**，进入即通关本层
- 🃏 **三选一强化**：每通关一层，从 3 张随机强化卡中选择 1 张，构筑你的流派
- 💀 **永久死亡**：撞墙、撞障碍、撞到自己都会终结本局，得分纪录自动保存
- 📈 **难度曲线**：层数越深，障碍越密、速度越快

## 强化卡池（8 种，可叠加构筑）

| 强化 | 效果 |
|---|---|
| 🛡️ 圣盾 | 抵挡一次致命碰撞（可叠加） |
| 🌀 相位穿越 | 穿过边界，从另一侧出现 |
| 🧲 食物磁铁 | 靠近的食物被自动吞食（范围+1） |
| 💰 黄金胃 | 食物得分 +50%（可叠加） |
| ⚓ 稳定锚 | 移速 -15%，操控更稳（可叠加） |
| ✂️ 瘦身剪 | 立即缩短 30% 的身体 |
| 🦎 断尾求生 | 每层一次：撞到自己改为断尾存活 |
| 🍀 幸运星 | 每层额外出现一个金色食物（+30分） |

## 操作方式

| 平台 | 操作 |
|---|---|
| 电脑 | 方向键 / WASD 移动 · 空格暂停 · 数字键 1/2/3 选卡 |
| 手机 | 手指滑动控制方向 · 点按卡片选强化 |

## 打包成可安装程序

同一套代码可以打包成各平台安装包：

- **Windows（exe）**：用 Electron + electron-builder 打包
- **安卓（APK）**：用 Capacitor + Android Studio 打包

详细步骤见 [docs/游戏打包与发布指南.md](docs/游戏打包与发布指南.md)
