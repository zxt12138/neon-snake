# 肉鸽贪吃蛇 Rogue Snake

肉鸽（Roguelike）+ 贪吃蛇的融合玩法：单图无尽模式，吞食豆子触发进化，技能皆有代价，分数里程碑伴随诅咒。单个 HTML 文件，零依赖，浏览器打开即玩。

## 在线试玩

直接用浏览器打开 `index.html` 即可。也可以在仓库 **Settings → Pages** 中开启 GitHub Pages（Source 选择 main 分支根目录），即可通过网址在线游玩。

| 豆子 | 颜色 | 得分 | 效果 | 来源 |
|---|---|---|---|---|
| 普通豆 | 红 | 10 | +1 长度 | 初始权重 90 |
| 黄金豆 | 金 | 50 | +2 长度 | 初始权重 5 |
| 过期豆 | 暗绿 | 1 | −1 长度（最短保留 2 节） | 初始权重 5 |
| 临时过期豆 | 暗绿空心 | 1 | −1 长度，**不刷新、不计进化** | 技能产生 |
| 临时黄金豆 | 金空心 | 50 | +2 长度，**不刷新、不计进化** | 技能产生 |
| 草帽豆 | 👒 | 初始 10，可养成 | 初始 +1 长度，**不刷新、不计进化** | 技能「草帽的传承」解锁 |

### 豆袋概率模型（加权随机）

想象一个装有 100 颗豆的袋子：90 普通 + 5 黄金 + 5 过期。技能加概率 = 往袋子里加豆子：

- 1 层 🍀 幸运星：袋中 +3 颗黄金豆 → 黄金豆概率 = 8/103 ≈ 7.8%
- 1 层 💰 黄金胃：袋中 +1 颗黄金豆
- 1 层 🤢 食欲不振：袋中 +10 颗过期豆 → 过期豆概率 = 15/110 ≈ 13.6%
- 1 层 🏃 我要减肥！：袋中 +5 颗过期豆
- 1 层 🥣 饥荒：袋中 +2 颗过期豆（层数越高加得越多）
- 1 层 💩 窜稀：袋中 +3 颗过期豆
- 1 层 💎 精致：袋中普通豆 ×0.95（90→86→81…，保底权重 20），普通豆积分 +10%
- 🗺️ 航海图每触发一次：袋中 +1 颗黄金豆（≈+1%），同时暴击率 +1%、草帽豆积分 +5
- 加某种豆只会轻微稀释其他豆的概率，不会直接挤占

## 玩法规则

- 🫘 **吞食进化**：累计吞食豆子到 **5 / 10 / 15 / 25 / 35 / 45 / 60…**（步进每 3 次升一档）触发一次进化
- ⏱️ **移速**：只随进化等级提升（每级 +5ms 步进，最快 80ms/步），吃豆不改变速度
- 🎲 **暴击**：拿到「小幸运」后吃豆积分有概率暴击（每层 +5%，初始 0%），「航海图」每吃 3 颗黄金豆额外 +1%；暴击时积分 ×2（在黄金胃/精致等加成之后翻倍）
- ⚠️ **里程碑诅咒**：每获得 1000 分触发一次**诅咒三选一**，必须选择一种诅咒才能继续（详见下方诅咒卡池）
- 🃏 **三选一技能**：每次进化从 3 张随机技能卡中选 1 张（唯一技能拿到后不再出现）
- ⚖️ **力量皆有代价**：选择技能会在地图上生成对应数量的随机障碍，障碍永久累积
- 💀 **永久死亡**：撞墙、撞障碍、撞到自己即本局结束，最高分自动保存
- 🫘 **多豆流**：拿到「2豆流 / 3豆流」后，场上同时存在 2 / 3 颗常驻豆（各自独立随机），吃掉其中一颗后其余消失并重新刷满
- 🕳️ **临时豆**：由技能产生的空心豆（临时过期豆 / 临时黄金豆），积分和长度效果与同类豆一致，但吃掉后不刷新新豆、不计入进化次数

### 👒 草帽豆玩法

拿到「草帽的传承」（唯一技能）后解锁特殊豆子**草帽豆**：

- **刷新**：选择该技能时、以及之后每次进化完，地图上刷新 1 颗草帽豆（场上最多 1 颗，没吃完不刷新）
- **性质**：类似临时豆——吃了不刷新、不计入进化次数
- **养成**：每吃一颗草帽豆，立刻三选一**永久强化模板**，之后刷出的草帽豆继承所有累计强化：
  - 🍖 分数强化：分数 +10
  - 🐌 稳重路线：分数 +1，长度 −1，移速 −5%
  - ⚡ 激进路线：分数 +30，长度 +1，移速 +5%
- **结算**：初始模板 10 分 / +1 长度 / 0% 移速；吃豆时按当前模板结算（移速修正吃时生效，加速上限 2 倍）
- **加成**：吃通用收益（黄金胃 / 小幸运暴击 / 通胀 / 腐烂），不吃类型专属加成（精致 / 饥荒 / 积少成多）

### ⚠️ 诅咒卡池（每 1000 分三选一，9 种）

🧱 **硬化障碍**每次必在选项中（常驻保底），其余 2 张从卡池随机：

| 诅咒 | 效果 |
|---|---|
| 🧱 硬化障碍 | 生成 1 个暗红色硬化障碍，无法被任何形式消除（圣盾撞不碎、大扫除清不掉、经济萧条无法转化） |
| 🏰 围城 | 地图边缘内侧生成一圈普通障碍（可清除） |
| 🕳️ 腐败之地 | 随机一块 3×3 区域被普通障碍填满（可清除） |
| 🧲 引力坍缩 | 所有普通障碍向地图中心聚拢一格（硬化障碍纹丝不动） |
| 💸 通胀 | 所有豆子积分 −10%（可叠加） |
| 🌀 逆风 | 移速 +3%，操控更飘（可叠加） |
| 🌫️ 迷雾 | 只能看清蛇头周围 5 格，其余区域变暗（唯一，拿到后不再出现） |
| 🦠 腐烂 | 豆子积分随移动贬值：每移动 10 格 −5%（可叠加，多层贬值更快；吃到时按当前价值结算） |
| ⛓️ 沉重代价 | 之后选择技能生成的障碍数量 ×2（可叠加；选卡界面会显示加倍后的真实代价） |

### 🎯 赏金任务玩法

拿到「赏金任务」技能后，地图上出现一条**金色路线**：

- 第 1 条路线 **5 步**，走完奖励 5×10 = **50 分**；第 2 条 **10 步**、每步 20 分（**200 分**）；第 n 条 5n 步、每步 10n 分，以此类推
- 每次完成后 **5 回合**刷新下一条
- 路线格永远不会被占用：生成时避开障碍/豆子，生成后新的障碍（含诅咒障碍）和豆子也不会落在路线上
- 踩上第一步后，之后每一步都必须精准踩在下一路线格上（下一步目标会金色高亮闪烁）
- **走错一步即任务失败，本局永远不再刷新赏金任务**
