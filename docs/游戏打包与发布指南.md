# 霓虹贪吃蛇：打包与发布完整指南

> 游戏本体是一个单文件 `index.html`，同一套代码可以打包成 Windows exe 和安卓 APK。

---

## 一、打包成 Windows 安装包（exe）

### 1. 准备环境
- 安装 [Node.js](https://nodejs.org/)（下载 LTS 版本，一路下一步即可）
- 打开命令行（Win+R 输入 `cmd`），输入 `node -v` 能显示版本号即成功

### 2. 创建打包项目
新建一个文件夹（例如 `neon-snake`），把游戏的 `index.html` 放进去，然后在文件夹中新建两个文件：

**`main.js`**（Electron 入口文件）：
```js
const { app, BrowserWindow } = require('electron');

function createWindow() {
  const win = new BrowserWindow({
    width: 640,
    height: 760,
    resizable: false,
    autoHideMenuBar: true,
    title: '霓虹贪吃蛇',
    webPreferences: { nodeIntegration: false }
  });
  win.loadFile('index.html');
}

app.whenReady().then(createWindow);
app.on('window-all-closed', () => app.quit());
```

**`package.json`**：
```json
{
  "name": "neon-snake",
  "version": "1.0.0",
  "description": "Neon Snake Game",
  "main": "main.js",
  "scripts": {
    "start": "electron .",
    "dist": "electron-builder --win"
  },
  "build": {
    "appId": "com.yourname.neonsnake",
    "productName": "霓虹贪吃蛇",
    "win": { "target": "nsis" },
    "files": ["main.js", "index.html"]
  },
  "devDependencies": {
    "electron": "^33.0.0",
    "electron-builder": "^25.0.0"
  }
}
```

### 3. 执行打包
在该文件夹下打开命令行，依次运行：
```bash
npm install        # 安装依赖（第一次较慢）
npm start          # 可以先本地运行测试一下
npm run dist       # 打包
```
完成后，安装包会出现在 `dist` 文件夹中（类似 `霓虹贪吃蛇 Setup 1.0.0.exe`，约 60~80MB）。
把这个 exe 发给任何人，双击安装即可玩。

## 二、打包成安卓安装包（APK）

### 1. 准备环境
- 安装 Node.js（同上）
- 安装 [Android Studio](https://developer.android.com/studio)（安装时勾选 Android SDK，默认即可）

### 2. 创建打包项目
新建文件夹（例如 `neon-snake-app`），把 `index.html` 放进一个叫 `www` 的子文件夹：
```
neon-snake-app/
└── www/
    └── index.html
```

### 3. 用 Capacitor 包装成安卓应用
在该文件夹下打开命令行，依次运行：
```bash
npm init -y
npm install @capacitor/core @capacitor/cli
npx cap init 霓虹贪吃蛇 com.yourname.neonsnake --web-dir www
npx cap add android
npx cap open android      # 会自动用 Android Studio 打开项目
```

### 4. 在 Android Studio 中生成 APK
1. 等 Android Studio 加载完成（右下角进度条走完）
2. 菜单栏选择 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
3. 完成后点提示中的 **locate**，得到 `app-debug.apk`

把这个 APK 发给任何安卓手机，点击即可安装游玩（手机会提示"允许安装未知来源应用"，同意即可）。

> 💡 想生成正式签名的 release APK：Build → Generate Signed App Bundle / APK，按向导创建密钥即可。

## 三、发布游戏，让别人下载

### 方案 A：itch.io（推荐，全球独立游戏平台）
1. 注册 [itch.io](https://itch.io) 账号（免费）
2. 点击右上角头像 → **Upload new project**
3. 填写：
   - **Title**：霓虹贪吃蛇
   - **Kind of project**：选 **Downloadable**
   - **Uploads**：上传你的 exe 和 apk 文件（勾选文件对应的平台：Windows / Android）
   - **Pricing**：选 No payments（免费）
4. 上传几张游戏截图作为封面，点击 **Save & view page**
5. 页面默认为 Draft，在页面底部点 **Edit game → Visibility → Public** 正式发布

发布后你会得到一个类似 `https://你的名字.itch.io/neon-snake` 的页面，任何人打开就能下载你的游戏。

### 方案 B：GitHub Releases
在仓库页面点击 **Releases → Create a new release**，把 exe / apk 作为附件上传，玩家直接从 Releases 页面下载。

### 方案 C：网盘直接分享（最简单）
把 exe 和 apk 上传到百度网盘 / 夸克网盘，生成分享链接发给朋友即可。
适合小范围分享，没有平台审核。

## 四、常见问题

| 问题 | 解决办法 |
|---|---|
| npm install 很慢 | 切换国内镜像：`npm config set registry https://registry.npmmirror.com` |
| electron-builder 下载失败 | 设置环境变量 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 后重试 |
| 手机提示"禁止安装未知应用" | 在手机设置中允许浏览器/文件管理器安装应用 |
| 想换游戏图标 | 在打包项目的 `build` 文件夹放一张 512×512 的 `icon.png`，electron-builder 会自动使用；安卓端在 Android Studio 中用 Image Asset 工具替换 |
